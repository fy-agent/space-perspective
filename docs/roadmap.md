# 产品路线

空间透视要帮助用户理解本地文件，作出有依据的整理决定。每个阶段都要能验证用户行为，
而不是只累积扫描数量或功能名。这里没有对外承诺的发布日期。

## 已提供：Mac 分类建议预览

- 系统目录选择器与 Downloads 只读授权。
- 类型与用途线索，清理、归档、重要、保留和待判断分组。
- 原因、证据、版本对照、需确认条件与下一步。
- 本轮保留决定与不执行的清理预览。

## 下一步：让处理可以放心交给软件

1. 解决延迟与重启后的 Trash 恢复身份问题，保留漂移与冲突保护。
2. 验证中断、部分失败、同名冲突、重启恢复与记录完整性。
3. 通过这些检查后，才开放用户逐项确认的真实文件处理。
4. 改善原生窗口的建议浏览、比较与选择体验，收集用户对建议质量的反馈。

## 后续：更准确地理解文件

- 明确授权下的精确内容去重与已安装软件核验。
- 本地正文解析、OCR、文档和图片的用途理解。
- 跨类型的项目关联、归档建议和更细的误判解释。

现有版本没有调用 AI 模型。未来内容理解需单独说明读取范围、数据去向与降级行为，
不把只读元数据授权扩大成正文或网络授权。

## 分发与平台

在 Mac 的处理与恢复闭环通过后，推进 Developer ID 签名、公证安装包和用户体验验证。
Windows 桌面版在其后复用规则与契约，并单独验证文件属性、权限、路径和恢复行为。
现有 Windows Core CI 不代表 Windows 桌面客户端已经完成。
